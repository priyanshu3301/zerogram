# Security Policy

## Supported Versions

Currently, only the latest release of Zerogram is supported with security updates. 

## Reporting a Vulnerability

Security and privacy are the core focus of Zerogram. If you discover any security vulnerability in the application, cryptography implementation, or data handling, please report it privately.

**DO NOT** create a public GitHub Issue for security vulnerabilities.

Please report security issues by emailing the maintainer directly. 
*(Maintainer: [priyanshu88011@gmail.com]).*

We will respond to your report as soon as possible, usually within 48 hours, and we will work with you to understand and patch the issue before a public disclosure is made.
